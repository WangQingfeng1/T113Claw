# 技能创建

帮助用户创建新的技能文件，扩展 T113Claw 的能力。

## 何时使用
- 用户说"创建一个新技能"、"教你一个新能力"
- 用户想自定义 Agent 的行为模式

## 使用方法
1. 与用户确认技能的名称和用途
2. 按照标准格式编写技能文件
3. 用 `write_file` 保存到 `skills/` 目录
4. 技能在下次对话开始时自动加载

## 技能文件格式
```markdown
# 技能标题

简短描述这个技能做什么。

## 何时使用
描述什么情况下使用这个技能。

## 使用方法
1. 步骤一
2. 步骤二（包括具体的工具调用）

## 示例
用户: "请求示例"
→ 工具调用示例
→ "预期回复"
```

## 命名规范
- 文件名用小写英文，单词间用连字符：`skill-name.md`
- 保存到 `skills/` 目录

## 注意事项
- 技能文件会注入 system prompt，保持简洁
- 说明应使用用户的语言
- 包含具体的工具调用示例帮助 Agent 理解

## 示例
用户: "创建一个翻译技能"
→ write_file {"path": "skills/translate.md", "content": "# 翻译\n\n在不同语言之间翻译文本。\n\n## 何时使用\n用户要求翻译时。\n\n## 使用方法\n1. 识别源语言和目标语言\n2. 直接使用语言能力翻译\n3. 用自然的表达方式回复\n"}
→ "翻译技能已创建，下次对话时会自动加载。"
