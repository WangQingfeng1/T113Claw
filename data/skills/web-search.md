# 网络搜索

当问题依赖外部世界的最新信息、在线文档、社区经验或产品资料时，优先使用 `web_search`。

## 何时使用
- 用户明确要求“搜索一下”“帮我查查网上怎么说”
- 问题涉及最新版本、近期新闻、外部教程、论坛排障
- 本地记忆、技能和代码库里没有足够信息
- 需要交叉核对多个外部来源

## 使用方法
1. 提炼搜索词，必要时补上产品名、芯片名、错误码、库名
2. 调用 `web_search` 获取 3 到 5 条高相关结果
3. 优先整理标题、来源、链接和核心结论
4. 如果结果互相矛盾，要明确说明不确定性

## Provider 选择
- 默认 `provider=auto`
- 若配置了 `tavily_api_key` 且 `domestic_only=0`，优先走 Tavily
- 若 Tavily 未配置、被禁用或请求失败，回退到搜狗移动搜索
- 只有在明确需要调试搜狗解析或网络环境确实受限时，才把 `domestic_only` 设为 `1`

## 搜索建议
- 查询太宽泛时，补充限定词，例如 `T113 Linux 快速启动`, `LVGL flex layout`, `DeepSeek tool calling`
- 需要限定站点时使用 `site` 参数，例如 `docs.lvgl.io`, `github.com`, `whycan.com`
- 对嵌入式 Linux 板卡，优先关注官方文档、开发者社区和实际排障文章

## 回答要求
- 先给结论，再给关键来源
- 尽量挑选不同来源，避免重复引用同一站点
- 链接要保留，方便用户继续阅读
- 不要把搜索结果原文大段复制进回答

## 示例
用户: "帮我搜一下 T113 Linux 快速启动优化"
→ web_search {"query":"T113 Linux 快速启动优化","max_results":3}
→ 汇总 3 条最相关结果，并说明哪些是启动链路优化、哪些是内核或 rootfs 优化
