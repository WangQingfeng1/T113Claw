# 记忆管理

管理用户画像、长期记忆和每日笔记。

## 何时使用
- 用户让你记住某些信息（偏好、习惯、重要事项）
- 用户问"你还记得…"或提到之前的对话内容
- 对话中发现了值得记录的新信息（用户姓名、兴趣、常用设置等）
- 用户要求查看或清理已有的记忆

## 使用方法
1. 先用 `read_file` 读取当前记忆：
   - `memory/USER.md` — 用户画像（姓名、偏好、习惯）
   - `memory/MEMORY.md` — 长期事实记忆
2. 判断新信息应写入哪个文件：
   - 关于用户本人的 → `USER.md`
   - 一般性事实/知识 → `MEMORY.md`
3. 用 `write_file` 将新信息追加到已有内容末尾（保留原有信息）
4. 自然地确认已记住

## 注意事项
- 不要覆盖已有信息，而是追加
- 保持每个文件简洁，用 Markdown 列表格式
- 敏感信息（密码等）不要记录
- 用户主动要求时才能删除记忆内容

## 示例
用户: "我叫小峰，喜欢喝咖啡"
→ read_file {"path": "memory/USER.md"}
→ 在已有内容后追加新信息
→ write_file {"path": "memory/USER.md", "content": "...原有内容...\n- 姓名：小峰\n- 喜欢喝咖啡\n"}
→ "好的小峰，我记住了你喜欢喝咖啡。"
